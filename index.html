Cómo recopilar noticias nuevas
  1. Abre el repositorio en GitHub y entra en Actions.
  2. Selecciona Actualizar noticias y publicar dashboard.
  3. Pulsa Run workflow y confirma con Run workflow.
  4. Cuando termine la publicación, pulsa Refresh en el dashboard.
